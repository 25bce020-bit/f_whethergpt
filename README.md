\# WeatherGPT 🌦️🤖



AI-Powered Weather Intelligence Platform — SIH Project



\## About



WeatherGPT is an AI-powered weather intelligence platform designed for the Smart India Hackathon (SIH).



The platform combines real-time weather information with AI-powered natural-language assistance, multilingual interaction, voice capabilities, weather alerts, visualizations, maps, and a modern interactive user interface.



The goal is to help users understand weather conditions naturally and make better decisions based on weather information.
